# Evaluation Discrepancy & Metric Attribution Audit

**Project**: Predictive AI-Assisted Adaptive Routing — Prediction Layer  
**Date**: November 2026  
**Auditor**: Production ML Systems Architect & Senior ML Engineer  

---

## 1. Executive Summary

A critical inconsistency was discovered across historical evaluation reports:
- `reports/final_test_results.json` recorded the model as **`"Moving Average"`** with:
  - MAE: `0.233719`
  - RMSE: `1.011918`
  - R²: `0.967482`
  - MAPE: `8.887765%`
- However, `reports/congestion_evaluation.json` and `reports/prediction_inspection_summary.md` recorded virtually identical metrics for **`amazon/chronos-2`** on the full test split:
  - MAE: `0.233717`
  - RMSE: `1.011846`
  - R²: `0.967486`
  - MAPE: `8.887762%`
- Meanwhile, for Moving Average on the test split, `congestion_evaluation.json` and `prediction_inspection_summary.md` recorded:
  - MAE: `0.249323`
  - RMSE: `1.079922`
  - R²: `0.962964`
  - MAPE: `9.408600%`

This audit investigated the source code and determined the exact root cause of the discrepancy.

## 2. Root Cause Analysis

### Code Inspection: `src/evaluate_chronos.py` (Lines 326–368 & 386–401)

In the historical implementation of `src/evaluate_chronos.py`:

```python
# Validation comparison on 2,000 chronological validation samples
valid_candidates = {
    k: results[k]
    for k in candidate_keys
    if "error" not in results.get(k, {"error": True})
}
best_key = min(valid_candidates, key=lambda k: valid_candidates[k]["MAE"])
# On validation subset:
#   Moving Average: MAE = 0.1772
#   Chronos-2 univariate: MAE = 0.1788
# Result: best_key was selected as "Moving Average"

# The script then called:
evaluate_on_test(best_key, results)
```

Inside `evaluate_on_test(selected_model_key, results)`:

```python
if "tiny" in selected_model_key:
  pipe = ChronosPipeline.from_pretrained(CHRONOS_TINY_ID, ...)
  ...
elif "covariate" in selected_model_key:
  pipe = Chronos2Pipeline.from_pretrained(CHRONOS_2_ID, ...)
  ...
else:  # chronos-2 univariate
  pipe = Chronos2Pipeline.from_pretrained(CHRONOS_2_ID, ...)
  # ... Ran Chronos-2 inference on all 180,900 test rows ...
  preds_test = [float(f[0, MEDIAN_QUANTILE_IDX, 0].item()) for f in forecasts]

test_metrics = evaluate_metrics(y_true_test, preds_test)

with open(out_path, "w") as f:
  json.dump(
      {"model": selected_model_key, "test_metrics": test_metrics}, f, indent=2
  )
```

### The Bug

Because `selected_model_key` was `"Moving Average"`, the string checks:
1. `"tiny" in "Moving Average"` evaluated to `False`.
2. `"covariate" in "Moving Average"` evaluated to `False`.
3. The execution fell through to the `else:` branch!
4. The `else:` branch **instantiated and executed `amazon/chronos-2` (univariate foundation model)** across all 180,900 test samples.
5. The resulting predictions (`preds_test`) were generated by **Chronos-2**.
6. The JSON serializer wrote `{"model": "Moving Average", "test_metrics": test_metrics}`, mistakenly stamping Chronos-2's test metrics with the label `"Moving Average"`.

## 3. Authoritative Comparison Matrix

From comprehensive inspection of `reports/congestion_evaluation.json`, `reports/prediction_inspection_summary.md`, and the row-level predictions in `reports/prediction_inspection_test.csv` (180,900 rows):

### B. Full Test Set (180,900 samples, 1,091 congested samples at > 50%)
*Objective: True out-of-sample evaluation under real peak traffic and link congestion.*

#### Continuous Forecast (Regression)
| Model | Test MAE | Test RMSE | Test R² | Test MAPE | Mean Bias |
|---|---:|---:|---:|---:|---:|
| **amazon/chronos-2** (univariate zero-shot) | **0.2337** | **1.0118** | **0.9675** | **8.89%** | +0.0097 |
| **Moving Average** (`util_mean_3`) | 0.2493 | 1.0799 | 0.9630 | 9.41% | -0.0022 |

#### Congestion Detection (Classification, Threshold = 50.0%)
| Model | Accuracy | Balanced Acc | Recall | Precision | Specificity | F1 Score | PR-AUC | MCC |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| **amazon/chronos-2** | 99.96% | **0.9880** | **0.9762** | 0.9586 | 0.9997 | 0.9673 | 0.9575 | 0.9671 |
| **Moving Average** | 99.96% | 0.9816 | 0.9633 | **0.9759** | **0.9999** | **0.9696** | **0.9913** | **0.9694** |

#### Confusion Matrix Comparison (Test Split, 180,900 samples)
- **amazon/chronos-2**:
  - True Negatives (TN): `179,763`
  - False Positives (FP): `46`
  - **False Negatives (FN): `26`**  *(missed only 26 out of 1,091 congested events)*
  - **True Positives (TP): `1,065`**
- **Moving Average**:
  - True Negatives (TN): `179,783`
  - False Positives (FP): `26`
  - False Negatives (FN): `40` *(missed 40 congested events)*
  - True Positives (TP): `1,051`

### Operational Trade-off
- **amazon/chronos-2** has higher **Recall (97.62% vs 96.33%)** and lower **False Negatives (26 vs 40)**. In proactive network routing, false negatives are catastrophic because congested links are routed over without penalty, causing packet drops. Chronos-2 proactively detects more congestion events.
- **Moving Average** has slightly higher **Precision (97.59% vs 95.86%)** and slightly higher F1 (0.9696 vs 0.9673) with fewer false alarms (26 vs 46).
- On the full test split, **Chronos-2 achieves both lower MAE (0.2337 vs 0.2493) and lower RMSE (1.0118 vs 1.0799)**.

## 4. Remediation Implemented

1. **Explicit Branching in `src/evaluate_chronos.py`**:
   - Replaced fragile substring matching with explicit checks for `"moving average"`, `"persistence"`, `"tiny"`, `"covariate"`, and `"chronos-2"`.
   - When `"Moving Average"` is evaluated, it directly runs `moving_average_baseline(test_df)`.
   - When `"chronos-2"` is evaluated, it runs `run_chronos2_univariate(test_df)`.
2. **Dedicated Output Isolation in `src/evaluate.py`**:
   - Legacy scikit-learn models now write to `reports/legacy_sklearn_test_results.json` to prevent accidental overwriting of `reports/final_test_results.json`.
3. **Full Validation Support in `src/evaluate_congestion.py`**:
   - Added `--full-val` flag to allow evaluating congestion classification across the entire 180,900 validation split before evaluating on test data.
4. **Historical File Preservation**:
   - Original `final_test_results.json` preserved with this clarifying audit document.
